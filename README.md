# مسيرة · من هو اللاعب؟

لعبة جماعية على جوال واحد: تظهر **مسيرة لاعب كرة قدم** (الأندية بالترتيب مع السنوات)، وكل فريق عنده وقت يخمّن فيه اسم اللاعب. لو كل الفرق ما عرفته ينكشف تلميح وتقل النقاط.

## طريقة اللعب
- من ١ إلى ٤ فرق، والصعوبة: سهل، متوسط، صعب، منوّع.
- وقت كل فريق: ٢٠ أو ٣٠ أو ٤٥ أو ٦٠ ثانية.
- النقاط: ٥ بدون تلميح، وكل تلميح ينقص نقطة (الجنسية، المركز، سنة الميلاد، أول حرف وعدد الحروف).
- بعد ٤ تلميحات وما أحد عرفه، ينكشف اللاعب بدون نقاط.
- الفريق اللي يبدأ يتبدّل كل جولة، واللعبة تحاول ما تكرر نفس اللاعبين بين الجولات.
- الإجابة تقبل العربي والإنجليزي والأخطاء الإملائية البسيطة (مثل «رونلدو» أو «كلوزة»).

## التشغيل على جهازك
ما يحتاج تثبيت شي. من داخل المجلد:
```bash
python3 -m http.server 8000
```
وافتح `http://localhost:8000` في المتصفح. (تقدر تفتح `index.html` مباشرة بعد، بس التشغيل بدون إنترنت يحتاج السيرفر.)

## الاختبارات
```bash
node --test tests/*.test.js
```
تختبر سلامة البيانات، مطابقة الأسماء، ودورة الجولة كاملة.

## هيكل المشروع
| الملف | وش فيه |
|---|---|
| `index.html` | الشاشات: الرئيسية، الإعداد، اللعب، النهاية |
| `css/style.css` | التصميم والهوية (الألوان في أول الملف) |
| `js/data.js` | **مكتبة اللاعبين**: هنا تضيف لاعبين جدد |
| `js/engine.js` | منطق اللعبة (النقاط، التلميحات، المطابقة) بدون واجهة |
| `js/app.js` | ربط الواجهة بالمنطق، المؤقت، الأصوات |
| `sw.js` + `manifest.webmanifest` | تشغيل بدون إنترنت وتثبيت على الشاشة الرئيسية |
| `assets/` | الشعار والأيقونات (منها 1024×1024 للآب ستور) |

## إضافة لاعب جديد
انسخ أي لاعب في `js/data.js` وعدّل بياناته:
```js
{ id: "unique-id", level: 2, name: "الاسم بالعربي", en: "English Name",
  aliases: ["طرق", "كتابة", "ثانية"], nat: "الدولة", flag: "🇸🇦", pos: "مهاجم", born: 1990,
  career: [["النادي الأول", "2010–2014"], ["النادي الثاني", "2014–"]] },
```
بعدها شغّل الاختبارات عشان تتأكد إن البيانات سليمة.

> آخر مراجعة للبيانات: نوفمبر 2026. انتقالات اللاعبين النشطين تمت مراجعتها من الأخبار، وقبل الإصدار تستاهل مراجعة أخيرة على ترانسفير ماركت.

## الطريق للآب ستور
1. **إكمال المحتوى**: توسيع المكتبة لـ 200+ لاعب، ومراجعة دقة المسيرات.
2. **التغليف كتطبيق iOS** باستخدام [Capacitor](https://capacitorjs.com/docs/ios) (مجاني): يحوّل نفس الملفات لتطبيق Xcode. يحتاج **جهاز ماك + Xcode**.
3. **حساب Apple Developer**: اشتراك سنوي مدفوع (99$ حسب صفحة Apple، تأكد من السعر وقت التسجيل): https://developer.apple.com/programs/
4. **الاختبار**: TestFlight مع أشخاص حقيقيين قبل النشر.
5. **صفحة المتجر**: لقطات شاشة، وصف، سياسة خصوصية، تصنيف عمري.

### ملاحظات مهمة للمراجعة
- **حقوق الصور والشعارات**: اللعبة حاليًا تعرض أسماء أندية ولاعبين كنص فقط بدون صور أو شعارات أندية، وهذا أسلم. لا تضيف صور لاعبين أو شعارات أندية بدون ترخيص.
- **الخط**: حاليًا يُحمّل من Google Fonts. قبل الإصدار نضمّن ملف الخط داخل التطبيق عشان يشتغل بدون إنترنت.

## الأمان وقوة التحمل
اللعبة حاليًا **بدون سيرفر وبدون حسابات**: كل شي يشتغل داخل الجوال، فما فيه بيانات مستخدمين تنسرق ولا ضغط على سيرفر.
- كل النصوص تنعرض بـ `textContent` (ما فيه حقن أكواد من أسماء الفرق أو الإجابات).
- سياسة أمان محتوى (CSP) تمنع تحميل أي سكربت خارجي.
- التخزين المحلي بس لإعداداتك وقائمة اللاعبين اللي طلعوا.

اختبار التحمل الحقيقي يصير مهم لو أضفنا لاحقًا: لعب أونلاين بين أجهزة، ترتيب عالمي، أو حسابات. وقتها نبني سيرفر ونختبره بأدوات مثل k6.
