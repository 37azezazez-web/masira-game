# هوية انتقالات

| الملف | الاستخدام |
|---|---|
| `wordmark-light.svg` / `.png` | الشعار الكتابي على الخلفيات الداكنة |
| `wordmark-dark.svg` / `.png` | الشعار الكتابي على الخلفيات الفاتحة |
| `symbol.svg` | الرمز لحاله (نقطتين وسهم الانتقال) |
| `icon.svg` / `icon-1024.png` | أيقونة التطبيق (1024 جاهزة للآب ستور) |
| `brand-guide.html` | دليل الهوية الكامل |

**الألوان:** أحمر الصافرة `#E03A2F` · حبر `#15171A` · ورق الألبوم `#EDEFE8` · أصفر البطاقة `#FFC82E` · أزرق الملعب `#2849D6` · أخضر العشب `#1F9D55`

الأسلوب: ستيكرات ألبوم الكورة، حدود حبر سميكة وظل صلب، بدون تدرجات ولا توهج.

**الخطوط:** Alexandria 900 للعناوين والأرقام، Readex Pro للنصوص. كلها مجانية من Google Fonts (رخصة OFL).

الشعار الكتابي محوّل لمسارات (outlines)، فيشتغل في أي برنامج بدون ما تحتاج الخط.
